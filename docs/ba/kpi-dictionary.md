# KPI dictionary — calculation contract 3.0

Effective 18 October 2026. Public source reference: 2026-10-12. Calculated results inherit synthetic/generalized evidence limits; private results inherit the linked records' classes and dates. Proposed accountability is not club acceptance.

| Measure                            | Formula / denominator                                                                  | Unit and grain                            | Source and exclusions                                                        |
| ---------------------------------- | -------------------------------------------------------------------------------------- | ----------------------------------------- | ---------------------------------------------------------------------------- |
| Cash inflow/outflow                | Annual amounts; FY25 independently summed from 12 months and categories                | USD / fiscal year, club-wide              | Raw synthetic financial sources → processed reference JSON; FY24 annual only |
| Net cash change                    | Inflow − outflow                                                                       | USD / fiscal year                         | Not bank balance, profit or runway                                           |
| Cash margin                        | Net cash change / inflow                                                               | % / fiscal year                           | Unavailable at zero inflow                                                   |
| Inflow/outflow ratio               | Inflow / outflow                                                                       | Ratio / fiscal year                       | Not liquidity coverage                                                       |
| Sponsorship concentration          | Sponsorship cash category / inflow                                                     | % / FY25                                  | Same period only; no FY24 category assumption                                |
| Cash comparison                    | Current annual result − prior comparable annual result                                 | USD / FY25 vs FY24                        | No invented monthly prior year series                                        |
| Public sample paid attendance      | Sum(paid) / selected fixture count                                                     | People / example home fixture             | Eight synthetic 2026 examples; not a season                                  |
| Public capacity fill               | Sum(paid) / sum(capacity)                                                              | % / selected fixtures                     | Opportunity-weighted, not mean percentages                                   |
| Public fixture contribution        | Sum(receipts) − sum(direct costs)                                                      | USD / selected sample                     | Before shared overhead; independent of annual cash                           |
| Returning paid share (public)      | Sum(paid × returning fraction) / sum(paid)                                             | % / selected fixture sample               | Modeled percentages, not tracked retention cohorts                           |
| Recorded paid attendance (private) | Sum approved linked paid counts                                                        | People / selected season/program/fixtures | Missing counts excluded and identified; complimentary separate               |
| Recorded receipts/costs (private)  | Sum approved linked amounts                                                            | USD / selected fixtures                   | Partial recorded totals labeled; missing is not zero                         |
| Recorded contribution (private)    | Sum(receipts − costs) only when every selected fixture has both                        | USD / selected fixtures                   | Direct and explicitly allocated shared costs; omitted expenses not inferred  |
| Source completeness                | Fixtures with both receipt and cost inputs / selected fixture count                    | Count / selected fixtures                 | Record coverage, not completeness certification                              |
| Returning paid share (private)     | Sum(returning counts) / sum(paid counts)                                               | % / selected program/season               | All counts must be present; zero paid denominator unavailable                |
| Sponsor face value                 | Sum visible contract values                                                            | USD / selected sponsor accounts           | Not cash receipts; Club-wide once and unallocated                            |
| Public delivery completion         | Sum delivered / sum contracted                                                         | % / selected sample assets                | Weighted asset ratio; empty unavailable                                      |
| Public overdue/renewal signals     | Count overdue assets / count Positive accounts                                         | Assets or accounts                        | Not probability, cash forecast or signed renewal                             |
| Private sponsor delivery           | Explicit status, owner, due date, evidence note                                        | Deliverable record                        | No generated reach or invented numerical obligations                         |
| Acquisition conversion             | Sample purchases / sample visits                                                       | % / club-wide 2026 sample                 | Not program attribution or a causal journey                                  |
| Channel acquisition cost           | Sample spend / purchases                                                               | USD / illustrative channel purchase       | Zero purchases unavailable; not ROI                                          |
| Home-kit quantities specified      | Numeric requirement rows / home requirement rows                                       | Count / generalized requirements          | Does not prove availability/readiness                                        |
| Open private actions               | Approved actions whose status is not Done                                              | Action record / organization              | Explicit owner/due/rationale, not generated business impact                  |
| Community allocation               | Scenario receipts × entered community fraction                                         | USD / conditional case                    | Not measured community reach or achieved impact                              |
| Scenario receipts                  | Capped attendees × unit receipts × home count + explicit sponsor allocation            | USD / explicit fixture/season             | Scope, complimentary, capacity and sponsor frequency mandatory               |
| Scenario entered costs             | Fixed/direct inputs × home count + attendee cost × capped attendance × home count      | USD / explicit case                       | Shared/omitted costs excluded unless allocated explicitly                    |
| Receipt risk allowance             | Attendee-linked receipts × (weather + operational fractions)                           | USD / explicit case                       | Deduction, not probability or observed loss                                  |
| Scenario contribution              | Receipts − entered costs − community allocation − receipt allowance                    | USD / explicit case                       | Conditional modeled result, not achieved profit                              |
| Scenario contribution margin       | Contribution / receipts                                                                | % / explicit case                         | Unavailable for zero receipts                                                |
| Scenario break-even                | Smallest whole attendance per home fixture with nonnegative same-equation contribution | People / home fixture                     | Funded zero, nonpositive increments and above-capacity results explicit      |
| Per-attendee receipts/costs        | Relevant total / capped attendance across explicit fixtures                            | USD / attendee                            | Unavailable at zero attendance                                               |
| Reconciliation difference          | Actual source sum − expected control                                                   | USD or rows / named control               | Seven deterministic pipeline checks; 24 web model controls                   |

## Definition access

The methodology gives equations and the independent $370 worked example. Public drill-downs and exports carry scope and source boundaries. Private KPI definitions can be opened by keyboard; fixture evidence lists linked records, evidence classes, reference dates and versions. CSV exports identify selected records, source IDs and dates; export time is separate from reference time.

A clean private dataset has zero fixture records but unavailable attendance, receipts, costs and contribution. A deliberately entered and approved zero is a valid numeric observation. No forecast, benchmark, attendance target, sponsor probability, savings or ROI is supplied to a new organization.
