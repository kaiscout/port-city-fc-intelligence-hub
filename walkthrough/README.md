# Three-minute walkthrough

This folder contains the final narrated portfolio walkthrough, its exact narration, and the application frames used to record it.

Rebuild on Windows:

```powershell
.\scripts\generate-walkthrough-audio.ps1
node .\scripts\record-walkthrough.mjs
```

The recording explains the problem, evidence boundary, modeled finding, owner decision, architecture, and controlled next step. All visible data is synthetic or generalized.
